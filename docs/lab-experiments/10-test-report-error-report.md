## 1. Aim
To execute the designed test cases, record the outcomes, and generate formal Test and Error Reports for the CCMS application.

## 2. Objective
- To summarize the execution results of the test cases.
- To calculate test coverage and analyze execution metrics.
- To document hypothetical academic defect scenarios for a thorough understanding of the defect lifecycle.

## 3. Theory
- **Test Report:** A document summarizing all testing activities, results, metrics, and overall software quality evaluation. It provides stakeholders with confidence regarding release readiness.
- **Error/Defect Report:** A log used to track bugs found during execution. A typical defect report includes ID, description, steps to reproduce, severity, and status. It facilitates communication between QA and Development teams.
